# 本地 Ollama 图表体验页

[Other language](spec.md)

## 目标和边界
本地 HTML 页面列出 Ollama 已安装模型，将用户请求发送给选中的本地模型，校验 ChartDocument 并渲染 ECharts，提供诊断和原始响应。保留先前未提交的评测工作。不执行模型代码、不直接调用远程模型服务，也不宣称 MCP/GenUI 集成；若在 Ollama 中选择云模型，数据处理取决于 Ollama 配置。

## 设计
独立的本地 Vite 开发服务器仅提供模型列表与图表生成接口，限定同源本机请求以及固定 Ollama 地址 `127.0.0.1:11434`。限制请求、响应与时长，仅接受规定字段，不接受模型配置 URL。系统提示使用权威 schema/能力，上一张有效图表可作为可选编辑上下文。浏览器校验后才提交；失败保留上一有效图，展示原始输出和诊断，支持取消及资源清理，绝不插入模型 HTML。支持完整 JSON 和单个完整 JSON 代码围栏。

## 验收
- AC-01：本地模型可选，输入需求后显示真实生成的图表数据与模型响应。
- AC-02：无效输出、服务不可用、取消/过期请求准确提示并保留上一有效图。
- AC-03：本机路由拒绝跨源、无效及超限请求，双模式沿用现有校验。
- AC-04：记录双语用法、自动测试、真实 Ollama/浏览器证据和限制；保留已有文件与变更。

## 限制和回退
仅用于本地开发，不是公开服务。遵守现有图表上限和可信 registry 规则。不宣称模型基准、所有供应商兼容、流式输出或协议事件。移除独立服务器/页面可回退。

## 缺少数据反馈（2026-10-31）
模型返回空对象时，用通俗文案提示没有可用图表数据和当前不支持联网查询，并保留上一张图。空响应原因不确定，不能当成模型内部推理的证据。
