# 标准 A2UI 方案

[Other language](spec.md)

## 目标与边界
通过真实上游宿主接入标准 A2UI，支持 ChartDocument intent 和原生模式，复用现有编译器和 runtime。不执行模型输入、不获取任意外部数据、不重新实现协议解析器、不发布包，也不宣称其他协议版本兼容。

## 契约、数据流和失败处理
宿主解析协议并解析组件数据，将完整文档交给适配器；runtime 负责校验、编译和渲染。宿主保留组件时，无效更新保留上一张有效图并返回诊断；不完整流不能提交。选择事件通过明确配置的宿主回调回传，registry 为宿主可信输入，沿用现有资源上限。宿主移除组件时释放图表和观察器。冻结公开 API 前需核实上游生命周期、重复标识和数据绑定语义。

## 验收和证据
- AC-01：真实上游宿主在浏览器展示双输入模式。
- AC-02：有效更新替换旧系列，不完整或无效更新保留上一有效图并报告错误。
- AC-03：选择事件到达宿主，组件移除后释放资源。
- AC-04：记录成功、失败和恢复示例、双语文档、浏览器测试与工程门禁证据。

## 依赖、发布和待决问题
实施前核实可安装上游包/宿主版本、自定义组件注册、绑定、生命周期、许可证和体积。COSUI Marklang 依赖 JSON 阶段经验；A2UI 独立版本化。SDK 可用性、流式语义、重复键、SSR/水合和真实模型行为待验证。移除适配器即可回退，不变更核心；不授权发布。
