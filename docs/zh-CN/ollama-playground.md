# 本地 Ollama 图表体验页

[English](../en/ollama-playground.md)

本机 Ollama 服务已经启动并安装模型时，在仓库根目录运行：

```sh
pnpm dev:ollama
```

打开 `http://127.0.0.1:5180/ollama.html`。从检测到的列表选择模型，输入图表需求**和数据**，点击生成。如果要修改上一张有效图表，勾选“基于上一张有效图表修改”。展开下方两个面板，可以查看、编辑 ChartDocument 和查看模型原始响应。输出无效或取消时，保留上一张图。如果 Ollama 未连接，请按自己的安装方式启动服务后刷新列表。

开发服务绑定 `127.0.0.1:5180`；限定同源的中间层只连接固定的 Ollama 地址 `127.0.0.1:11434`，不接受模型指定的地址，也不执行模型代码。请求发送到本机 Ollama；若 Ollama 配置使用云模型，数据处理取决于该配置。此页面不涉及 MCP 或 GenUI 协议。它会将用户实际输入，以及勾选时的上一张图表文档发送给 Ollama；ChartNexus 不会持久化响应。

服务限制请求 1 MiB、提示词 12000 字符、响应 2 MiB、生成时间 120 秒。服务请求 JSON，也允许单个完整 Markdown JSON 代码围栏。模型输出必须通过既有 ChartDocument 校验与能力/尺寸限制后才渲染；不支持或缺失的数据由诊断提示，应用不会代为补造。校验不保证模型生成的数值与请求一致，请核对图表和文档。这是本地开发工具，不用于公网服务，也不保证模型结果正确。生产静态构建不包含此本地中间层。

2026-10-31 本地证据：Chromium 149 与本机 `qwen3.5:9b` 对给定 120/180/150 生成柱状图，又将其改为折线图并保留数据。浏览器测试另外模拟了服务不可用、取消、无效 JSON 和原生 option 校验。其他模型及 Ollama 配置可能表现不同。参见 [SPEC-0009](../../specs/0009-ollama-playground/spec.zh-CN.md)。

模型返回空对象时，页面会提示未提供可用图表数据，且当前页面不会联网查询。空响应的具体原因无法确定。
