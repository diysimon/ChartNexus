# 模型资源与离线评测

[Other language](spec.md)

## 问题、范围与设计
现有 MCP 提供 Schema、能力清单和两个 recipe，但缺少双语模型入口和模型任务集。本阶段交付版本化的 20 条合成离线开发任务、数据划分说明、确定性候选结果评测器，以及引用权威来源的模型/RAG 资源。不调用模型，不宣称训练数据、视觉适宜度评分、发布或远端客户端验证。

候选输入是以任务 ID 为键的 ChartDocument 或诊断码/路径 JSON 对象。评测器复用现有编译器，按任务检查可观察的渲染计划或诊断码，分别报告有效性和任务断言。自检验证参考样例和负面控制，不代表模型能力。数据只在本地处理，不执行代码或访问网络，沿用编译器限制；缺失候选失败、额外 ID 拒绝，数据引用仅使用显式 fixture registry。

## 验收
- AC-01：20 个稳定双语合成任务覆盖四类图、原生配置、编辑、数据语义与诊断，每项有可执行断言。
- AC-02：参考样例通过且故意错误的候选失败；可评分外部候选 JSON，不要求文档逐字一致。
- AC-03：双语入口与版本化检索索引引用权威 Schema/能力/示例，MCP 暴露索引；漂移检查与 stdio 测试覆盖。
- AC-04：`pnpm check` 和离线评测通过，文档区分本地 fixture 与未验证的真实模型/训练使用。

## 兼容与发布
新增资源和脚本，不改变工具输入或 core；删除任务集/索引及 MCP 资源可回退。家庭划分元数据不能被称为保密测试集。人工审美评审、真实模型指标和模型供应商接入留待后续。详见任务。
