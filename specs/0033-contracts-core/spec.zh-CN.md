# M1 契约与核心边界

## 范围与已定设计
实施 A04/A05 及 A16 评测框架基础。冻结 0.3 的十一种判别分支、三个数据族、投影与显式迁移。现有七种图表可编译，雷达/树/桑基/地图只冻结结构，M3 前不得声称渲染支持。拆分校验、数据、变换、图表与展示，保留旧版本数值语义。

## 验收（pass；见[证据](tasks.zh-CN.md)）
- AC01：十一种分支均有正反例及完整/投影 Schema 等价性测试；缺失类型专属配置在结构层失败。
- AC02：显式迁移保留语义，正确转换主题并校验稳定键；预留类型编译返回未支持。
- AC03：拆分后七种图表 golden 及已有变换/身份语义不变；核心无 DOM/网络/模型 SDK 依赖。
- AC04：同步 Schema、能力和 Agent 资源；开发/独立评测框架分离答案，单独评分数据保真。

## 失败、限制、依赖与交付
依赖 M0 与审视 RFC。验证/渲染/传输失败保留已提交图表；不执行输入。保留 1 MiB、4096px 等限制；暂存最多 16 图，旧新源码共存限 2 MiB。新契约采用 0.3 或宿主显式启用，不自动迁移。核心不依赖 DOM/网络/模型 SDK。同步双语文档、清单、生成资源与测试。回退禁用新版本/宿主选项，不删除旧数据。证据写入 tasks，外部不可用记 not-run；不进行 Git 或外部发布。
