# 顺序更新协议接入与流缓冲加固
[English](spec.md)
## 目标
将宿主显式提供操作顺序的可选模式扩展到 OpenUI 和 COSUI JSON，同时兼容既有文档模式；加固宿主流缓冲并提供面向模型的用法。这是 ChartNexus profile，并非协议本身的保证。
## 十项工作
1. 为 OpenUI 增加可选顺序模式、回执和生命周期管理。
2. 为 COSUI JSON 增加可选顺序模式、回执和生命周期管理。
3. 提供可运行的 OpenUI 顺序更新示例。
4. 提供可运行的 COSUI 顺序更新示例。
5. 在真实浏览器验证 OpenUI 顺序、流式状态和恢复。
6. 在真实浏览器验证 COSUI 顺序和恢复。
7. 加固流缓冲和输入边界。
8. 增加流式和顺序回归测试。
9. 更新面向 Agent 的诊断和用法资源。
10. 同步双语文档、manifest 并执行工程门禁。
## 验收与边界
宿主在任务开始前捕获基础版本并提供操作 ID。未完成、重复、过期和失败操作保留上一有效图，只有运行时成功才推进版本。OpenUI 流式过程中不提交。旧模式保持行为。回执是宿主回调而非标准协议事件。每个挂载图表独立拥有控制器。COSUI Marklang、真实模型流、交互状态保持、发布包和外部集成不在此范围；如实记录验证及未完成项。

## 证据
本机 Chrome 浏览器测试覆盖两个顺序模式和两个原有模式；`pnpm check` 覆盖类型检查、lint、单元测试、资源生成和示例构建。真实模型传输及其他排除项未验证。
