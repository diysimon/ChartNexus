# 项目章程与范围

[English](../en/project-charter.md)

## 定位
ChartNexus 是面向大模型、Agent 和生成式 UI 的 Apache ECharts 图表基础设施。它提供可版本化的图表契约、校验与编译、渲染运行时、协议适配器及模型资源。
项目目标是降低使用 ECharts 的门槛，并提高生成、修改和交互的可验证性。模型无关意味着不绑定厂商，不代表所有模型具有相同成功率；协议无关意味着适配器可扩展，不代表已经支持全部协议。

## 用户与任务
- 应用开发者：把模型输出嵌入现有产品，保留现有数据权限和前端技术栈。
- Agent 开发者：发现能力、获取最小必要规范、校验并修复图表。
- 协议与框架维护者：通过稳定契约接入 ECharts，不复制编译与渲染逻辑。
- 资源使用者：使用有版本、来源、许可和验证记录的检索与训练资源。

## 产品原则
1. 保留 ECharts 原生表达能力，同时提供受控的简化 intent 模式。
2. 数据、图表描述和 UI 状态分离；模型不得被要求重写大批真实数据。
3. 相同输入、编译器版本、数据版本和显式环境参数产生可复现的渲染计划。
4. 失败应有结构化诊断；不得通过丢字段、改数值或执行模型代码来伪造成功。
5. SDK、CLI、MCP、UI 适配器复用同一核心；核心无模型凭证也可运行。
6. 文档、示例、Schema、能力清单、评测与实现共同交付。

## 责任边界（当前）

ChartNexus 负责版本化契约、受支持输入的正确处理和渲染、诊断、有界适配器与可用资源。宿主负责是否请求或调用图表、数据事实和授权、模型选择及服务运营。模型易用性实验用于改进资源；模型选择率和事实正确率不是 SDK 发布门槛。保留输入数值、单位、空值及明确声明的转换。详见[产品边界](product-boundary.md)。以下版本范围是历史规划，不代表当前发布状态。

## v0.1 alpha 范围
- JSON 原生 option 入口及已声明的能力边界。
- intent：柱状、折线、饼图、散点；显式字段映射。
- 小型内联数据、宿主注册的数据引用及版本。
- 校验、编译、浏览器 DOM 渲染、静态 SVG。
- 完整描述替换、数据替换、基础选择事件。
- CLI、本地 stdio MCP、一个 UI 协议集成、模型资源和离线示例。

## v0.2 beta 范围
第二个 UI 协议、更新冲突与重复请求处理、交互状态保留、公开兼容矩阵、跨模型评测和发布流程。跨协议状态正确性在 alpha 就设计，在 beta 扩大验证。

## 暂缓范围
通用 BI、数据库查询引擎、任意代码执行、托管模型代理、专用模型训练、完整 ECharts option Schema、所有前端框架、原生移动端渲染和全部协议的无条件兼容。PNG、复杂图表扩展和远程 MCP 按需求排期。
