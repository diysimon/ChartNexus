# 分类图表显式聚合
[English](spec.md)
## 契约
实验性 0.2 intent 柱状、折线和饼图允许显式声明 `chart.aggregate: { op: "sum" | "mean" | "count" }`。按编码 x 分类及可选系列字段分组，保持分类和系列首次出现顺序。`count` 统计非 null 数值 y；sum/mean 忽略 null，全为 null 时结果为 null。不存在的分类/系列组合为空位，不是聚合结果。不声明则绝不聚合，不进行类型转换。先校验源表和 revision；无效值、不支持的散点、带 y 单位的 count 以及非有限算术结果须拒绝。有限 IEEE-754 运算不保证十进制精确算术。聚合后的饼图仍遵守非负且非 null 约束。
## 身份与隐私
与渲染点对齐保留聚合来源信息：操作、分类、系列（无分组时为 null）、输入行数及非 null 输入行数。聚合选择事件的 identity 为 `aggregate`，rowIndex 为 null，绝不伪造单行；不暴露原始行数据或行索引，范围受图表和数据 revision 限定。缺失组合没有聚合来源。排序须同步调整来源。非聚合图表的原位置选择契约不变；宿主可以通过自己的数据层选择进一步披露。
## 验收
覆盖 null、零、重复值、首次出现顺序、分组空位、所有操作、溢出、count/单位冲突、排序后来源、日期、引用版本、输入不变、渲染和浏览器选择；如实说明限制，不改变 0.1。不声称模型准确率、真实远程流或稳定行 ID。

证据：单元与 SVG 测试覆盖聚合及来源，本机 Chrome 测试验证聚合选择事件。未执行真实模型评测。
