# 产品边界与责任划分

[English](../en/product-boundary.md)

ChartNexus 提供版本化图表文档、校验与编译、浏览器与 SVG 渲染、固定版本的 GenUI 适配 profile，以及面向模型的资源。宿主提供完整数据或已授权的数据引用。输入经过可选的协议适配 → ChartDocument → 校验/编译 → 渲染器 → 宿主组件。不使用 MCP 或模型服务也可以直接使用渲染器。

| 责任 | ChartNexus | 宿主 / 数据 / 模型 |
| --- | --- | --- |
| 是否画图、是否调用组件 | 描述支持的能力和输入 | 决定并调用组件 |
| 业务数据的真实性、来源和授权 | 校验支持的数据结构与引用，不推断事实 | 查询、授权并核实数据 |
| 展示已提供的数值 | 保留数值、单位、空值、身份与明确声明的转换；报告不支持的输入 | 选择明确的操作并提供合适的容器 |
| 错误、不完整或过期的输出 | 返回诊断；在所选运行时/适配器明确保证时保留上一张图 | 拼接完整消息，管理重试、顺序和降级 |
| 主题和信息密度 | 在可选聊天 profile 中提供受限的明暗主题、透明背景与五档密度 | 设置宿主策略并保证周围背景可读 |
| 模型接入 | 提供 Schema、能力、示例和诊断，验证资源可用性 | 选择和配置模型、提示词及工具；不保证模型调用或生成准确 |

项目不查询事实、不静默修改业务数据、不执行模型代码、不开放任意 ECharts 配置，也不保证兼容所有协议或模型。guarded native 校验是部分校验。Schema 校验不能证明事实正确、安全认证通过或选图合理。既有模型评测只反映特定设置，用于诊断，不是通用产品验收阈值。模型未选择组件或生成的事实不准确，不属于 ChartNexus 渲染错误。

生产接入前应验证具体宿主/SDK/浏览器、流式拼接、错误处理、资源限制、交付版本及运行策略。服务端渲染和远程服务还需要宿主侧隔离与访问控制；本地 stdio MCP 不能直接当公网服务。见[支持矩阵](support-matrix.md)和[快速接入](getting-started.md)。
