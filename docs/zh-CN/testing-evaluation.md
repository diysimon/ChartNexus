# 测试、评测与验收要求

[English](../en/testing-evaluation.md)

## 测试层级
| 层级 | 必测行为 |
| --- | --- |
| 契约 | 两种模式互斥、未知字段、版本拒绝、诊断结构 |
| 编译 | 正常映射、空值/时间/单位、输入不变性、确定性 |
| 状态 | 过期更新、重复操作、删除系列、失败保留、销毁后迟到结果 |
| 浏览器 | 挂载、零尺寸、resize、事件、清理、切换图表 |
| 适配器 | 原生宿主注册、数据绑定、流式部分状态、错误、事件回传 |
| 分发 | Node 导入无 DOM、tarball 实际安装、peer 缺失诊断 |
| 模型 | 初次生成、多轮修改、诊断修复、数据保真 |

视觉快照只覆盖有意义的布局和回归；禁用动画，固定字体、DPR、尺寸和浏览器。截图相似不证明数字正确，数值与字段必须另测。外部宿主需要实际运行证据，mock 只证明适配器局部契约。

## 首批评测集
建议 100 个独立任务：创建 30、多轮修改 25、数据语义 20、错误修复 15、协议状态 10。数量是构建目标，不是已存在的资产。先用 20 个任务在 P0 验证设计，再扩展。
同一任务可以有多个合理图表，不以单一 option 字节快照判模型失败。定义不变量、允许解集合、数值结果和交互预期。人工审阅图表选择合理性，与自动可渲染率分开报告。

## 对照与运行记录
比较：直接生成原生 option；原生 option + 校验诊断；intent + 编译器。固定任务与数据、等价上下文和预算；记录额外资源检索与工具调用的成本。
记录 provider/model 精确 ID、运行日期、参数、提示词与 Schema hash、能力版本、数据版本、随机种子（若支持）、尝试次数、终止原因、token/费用/耗时。随机模型需多次运行并报告样本数和波动；不得挑选最佳一次作为整体结果。
最大修复次数和预算在运行前声明。格式修复和模型语义修复分开统计。按 task family 隔离 train/dev/test，模板与数据近重复不能跨集。

## 指标
首次结构合法率、端到端任务成功率、有限重试修复率、字段/数值保真率、多轮修改正确率、事件正确率、token、成本、延迟。区分结构合法、编译成功、渲染成功、语义正确四层。
模型易用性实验可测量这些指标，用于改进文档与接入。模型是否调用组件及事实准确性由宿主负责，不是 SDK 验收或发布门槛。不虚构指标作为已达成结果；离线轨迹回放不代表真实模型评测。

## 性能与资源
用公开合成数据覆盖小型常见规模和接近限制规模。分别测编译、初次渲染、更新、释放后的资源。记录硬件、浏览器、数据大小、图表类型与 p50/p95。P0 确定限制和基线，超预算必须诊断或受控降级，不能静默采样改变图表含义。

## 发布验收
所有必需 AC 有证据；无已知未处理的数据改写、任意代码执行或状态损坏缺陷；契约与派生资源同步；支持版本都有证据；未验证能力明确标识；双语说明、许可和迁移文档齐备。
测试覆盖率是辅助信号，不能用总百分比替代关键行为检查。发现缺陷先补可复现回归，再修复与验证。

## 已实现的开发样例（2026-10-31）
现有公开合成 20 任务开发集及离线候选评分器，详见[评测基线](evaluation-baseline.md)。100 项任务集、隐藏数据划分、人工评审与真实模型运行仍是后续工作；样例自检不能证明模型表现。
