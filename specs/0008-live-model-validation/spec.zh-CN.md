# 本地模型与 MCP 验证

[Other language](spec.md)

## 目标与范围
使用公开合成任务和官方 MCP SDK stdio 客户端，针对实际本地 Ollama 模型开展可复现、有限范围的试运行。保留现有任务集和评分器。不调用远程模型、不使用私人输入或密钥、不宣称隐藏基准、训练、模型排名或发布。

## 契约和安全
运行器向模型发送任务提示词、明确提供的数据/上一轮或输入文档、Schema 和能力 profile；不提供参考输出、预期断言或检索答案。要求模型在输出 JSON 前通过真实 MCP 工具校验。将元数据、服务提供的 token 计数、耗时、工具调用名称及结果、原始输出和得分写入显式指定的本地忽略输出目录。限制任务数、请求大小、生成量、工具轮次与超时，完成后关闭客户端。失败任务必须记录，不得静默跳过。沿用现有编译器预算；服务仅允许本机地址；不执行模型输出的路径、命令或任意工具。

## 验收
- AC-01：版本化运行器对选定任务使用真实本地模型，生成候选、可复现元数据与评分，提示词不泄露参考答案。
- AC-02：运行器发现并调用真实 MCP stdio 服务，分别记录发现和模型发起调用是否成功。
- AC-03：测试失败边界、无效模型输出、缺失 ID、工具限制及离线行为，执行工程门禁。
- AC-04：提供双语运行说明与真实小样本记录，列明模型、失败和未验证项。

## 依赖和限制
依赖已启动的本地 Ollama 服务和已安装模型；设备、运行时、模型结果可能不同。任务为公开开发数据，不是独立隐藏基准；模型输出不可信。不宣称桌面客户端集成或模型比较。可删除运行器和文档回退，不修改 core。

## 证据与限制
真实本地 Ollama + 官方 MCP stdio 试验和宿主发起的 SVG 哈希校验见[试运行指南](../../docs/zh-CN/local-model-pilot.md)。不宣称远程模型、桌面客户端、隐藏集对比、完整 20 项或重复试验已完成。
