# M2 聊天宿主质量

## 范围与已定设计
实施 A06–A11：尺寸感知纯展示、主题、完整数据表与键盘访问；等待尺寸挂载、Marklang 事务暂存、稳定键与兼容图例保留；中立流缓冲、真实 Ollama NDJSON 终止/取消/修复；四宿主验证。不包含 M3 新图表、自动事实查询、远端发布或未声明的缩放能力。

## 验收（pass；见[证据](tasks.zh-CN.md)）
- AC01：宽 240/320/480/768、高 240/320/480 与明暗主题/五档组合可展示或显式回退；resize 不改修订。
- AC02：声明背景上的对比度合格；完整数据、null、单位、身份可访问；具备键盘控件及静态摘要/数据元信息。
- AC03：初始隐藏挂载恢复且仅有一个实例；销毁取消等待；Marklang 暂存失败保留旧节点与实例。
- AC04：重排保留稳定键；兼容图例保留；删除、新增及不兼容系列正确处理；失败不改修订。
- AC05：UTF-8 拆分、帧解析、截断/无终止、取消、epoch/修订和有界修复不误提交；取得真实本地 Ollama 流式证据。
- AC06：固定真实 OpenUI/A2UI/COSUI JSON/Marklang 宿主覆盖适用契约，明确不支持的功能格。

## 失败、限制、依赖与交付
依赖 M0 与审视 RFC。验证/渲染/传输失败保留已提交图表；不执行输入。保留 1 MiB、4096px 等限制；暂存最多 16 图，旧新源码共存限 2 MiB。新契约采用 0.3 或宿主显式启用，不自动迁移。核心不依赖 DOM/网络/模型 SDK。同步双语文档、清单、生成资源与测试。回退禁用新版本/宿主选项，不删除旧数据。证据写入 tasks，外部不可用记 not-run；不进行 Git 或外部发布。
