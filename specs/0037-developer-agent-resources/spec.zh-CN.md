# Developer and agent resources

[English](spec.md)

## 问题与目标
项目能力与示例入口分散，模型资料需要可检索并与实现同步。固定产品边界：宿主负责调用决策、数据事实和权限；ChartNexus 负责协议、校验、受支持数据的正确展示、诊断及有界兼容。目标是让开发者能从零运行、复制并理解失败恢复，让 Agent 可发现受支持的版本、图表、配方与宿主约束。

## 非目标与设计
不增加模型供应商依赖，不查询事实，不将模型调用率或真实数据正确率设为 SDK 质量门槛，不修改现有 ChartDocument 契约；不发布 npm 或上传数据。以现有 Schema、能力、配方和运行时为权威源；增加可运行的浏览器快速示例、中英文指南，以及由生成器同步到索引、JSONL 与 MCP 的双语检索资源。Map 仍由宿主注册，其他协议的版本限制不变。

## 兼容、资源、回退
不变更原有输入、输出、预算或数据行为；新文档和检索条目为附加资源。回退时删除新示例和资源入口并重新生成，不迁移用户数据。无待决产品选择；实机、真实生产宿主及训练效果未在本任务中验证。见[任务](tasks.zh-CN.md)。
