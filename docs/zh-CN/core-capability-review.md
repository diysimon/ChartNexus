# 核心能力盘点与任务审查
[English](../en/core-capability-review.md)

审查基线：工作区 2026-10-31 的实验性 0.1 实现，包含尚未提交的更改；不是发布声明。依据 [Schema](../../packages/schema/src/chart-document.schema.json)、[编译器](../../packages/core/src/index.ts)、[原生校验](../../packages/core/src/native.ts)、[runtime](../../packages/runtime/src/index.ts)、[能力清单](../../packages/core/src/capabilities.json) 和 [测试](../../tests/core.test.ts)。图表类型可编译不代表所有选项正确、所有环境和模型均已验证。

证据记号：**T** = 现有自动化测试覆盖该行为；**P** = 本次调用 `compileChart` 的定向探针；**S** = 源码静态审查；**N** = 目标功能不存在或此任务未验证。T/P 并非产品级完整验收，浏览器证据另行说明。

下表保留 0.1 审查基线；此后已新增实验性 0.2 子集，见[开发指南](development.md)。

## 优先问题

1. **P0：原生语义校验差距。** 嵌套无效字段会被接受，成功不表示字段生效；应提供机器可读校验级别和明确的未知字段策略，防止 Agent 将 compile 成功误当作图表正确。
2. **P0：数据语义。** temporal、单位、聚合、排序、空值与缺行均需明确，不能静默转换或编造数据。
3. **P1：表达力与默认值。** 方向、面积、环形、标签、图例及颜色需要与渲染一致的声明方式。
4. **P1：状态与身份。** 当前 operation 仅完整文档、会话内有限去重；事件是位置身份，不是稳定实体。
5. **P1：主题与环境一致性。** 需固定预设版本、覆盖顺序、字体/locale/尺寸条件，分别验证 DOM 与 SVG。
6. **P2：证据与评测。** 公开 20 题不是独立测试；补足跨图表数值不变量、视觉检查、性能和未见过的数据。

后续协议与兼容建议见 [0.2 草案](core-protocol-0.2.md)。本次未运行 28 个任务的完整模型、浏览器或视觉评测。
