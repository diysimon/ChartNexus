# intent 占比语义与可区分分组
[English](spec.md)

## 范围与证据
实现审视中的 A02 / F01–F02。目前全零饼图会画成等分扇区，空分组值可能与数值字段名碰撞。修复 0.1/0.2 intent（含环形），不改变原生模式、不新增图表类型。

## 契约与设计
饼图显式禁用零和扇区与空白占位圆。非空且全零的饼/环形在 RenderPlan 中可选返回 dataState `no-share`、非致命 NO_SHARE_DATA notice、可见副标题及 ARIA 描述。空饼图为 dataState `empty`，无 no-share notice；正常正值不含异常状态。数值与行/聚合身份不变。聊天 minimal 可隐藏原始标题，但必须保留无占比说明。漏斗借用饼图编译时，不得继承饼图专属配置或无占比语义。

分组系列 ID 由分组字段、原始分组值和数值字段确定。非空原始名称保持不变。空分组显示 `(empty)`；若被占用，选择从 2 开始首个未占用的 `(empty) [n]`，根据全部原始分组值决定，不受行顺序影响。可选 seriesMetadata 记录 ID、分组字段、原值、显示名。重排不改变同一语义系列 ID；改变分组/数值字段则改变 ID。现有分组 ECharts ID 会改变，调用方不可跨编译器版本持久化旧 ID。事件仍是原有位置/聚合契约，本任务不新增稳定行 ID。

输入 Schema 不变，输出元数据为增量字段。core 决定语义，浏览器/SVG 共用 option；Agent 校验转发 notice/state。公共信息使用英文，宿主可按 code 本地化。保留饼图对 null 的拒绝及原生行为。资源限制不变，名称消歧受最多 50 系列约束。
