# 核心 0.2 基础
[English](spec.md)
## 目标
新增实验性的独立校验 0.2 intent profile，支持横向柱状、面积折线、环形饼图和带版本的命名视觉预设。保持 0.1 语义，提供显式无损的 0.1 到 0.2 转换并说明原生模式校验边界。
## 范围与设计
0.2 由宿主显式选择，复用现有数据语义、编译器、预算和安全检查。命名配置为小范围纯 JSON 白名单，模型不能提供主题代码或外部资源。横向柱状将逻辑 x 分类映射物理 y 轴，逻辑 y 数值映射物理 x 轴。面积仅用于折线、环形仅用于饼图、横向仅用于柱状。主题预设直接编译到 option，无需运行时注册主题。未知 0.2 字段和不支持的组合须拒绝。转换校验 0.1 文档，只转换受支持的 intent，原生模式迁移明确报错。本增量不实现聚合、时间、单位、原生 0.2、实时主题切换、patch、外部主题，也不声称无障碍保证。
## 验收
测试版本隔离、迁移、无效组合、数据与输入不变性、确定性、主题 option、SVG 和浏览器渲染；同步能力、模型资源、双语文档与 manifest。测试不能证明真实模型表现或完整无障碍。
## 依赖
现有 Schema、编译器、SVG 渲染和浏览器 runtime；此前 0.2 提案在稳定前仍可调整。用户要求的其他路线阶段明确标为未完成。

证据：0.2 单元/SVG 测试、本地 Chrome 示例以及 stdio MCP 资源和校验测试通过；完整路线图、真实模型与无障碍评测尚未完成。
