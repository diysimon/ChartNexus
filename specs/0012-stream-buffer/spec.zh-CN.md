# 流式文档缓冲
[English](spec.md)
## 目标与边界
帮助宿主缓冲已解码的 JSON 文档片段，不向 A2UI 数据模型发布不完整文档。完成后通过现有顺序更新 profile 校验与渲染。本工具不实现模型、网络、A2UI 分帧或传输取消。
## 契约
工作开始时捕获基础版本和唯一操作 ID，创建一次性缓冲器。追加解码后的文本，只有传输成功完成后才能显式 finish。finish 解析单个 JSON 值并返回完整 operation；运行时负责在渲染前校验文档。取消、错误、超限均丢弃缓冲数据。限制为 1 MiB UTF-8 文档及 16384 个分片。字节流增量解码和中止、关闭传输由宿主负责。失败或取消后缓冲器不可复用，重试须新建；过期结果仍由顺序控制器拒绝。
## 验收
单元测试覆盖分片、Unicode 边界、体积、无效 JSON、取消和终态。浏览器测试在 A2UI processor 中使用真实 ReadableStream，覆盖片段、完成、取消和错误恢复并保持旧图。不声称真实模型或远程传输验证。
## 回滚
移除可选宿主工具和示例即可；现有图表和适配器契约保持不变。

证据：本机 Chrome 的 A2UI 浏览器测试 3/3；缓冲器单元测试纳入 `pnpm check`。远程或模型传输：未验证。
